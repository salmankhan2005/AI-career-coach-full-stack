# AI Career Coach (Full Stack)

An AI-powered career coaching, interview preparation, resume analysis, and career roadmap generation platform.

## Features

- **AI Q&A & Mock Interview**: Practice tailored interview questions and receive intelligent feedback.
- **Resume Analyzer**: Deep resume screening and optimization insights.
- **Roadmap Generator**: Personalized step-by-step career path roadmaps.
- **Cover Letter Generator**: Create tailored cover letters in seconds.
- **Interactive Dashboard & History**: Track progress, past conversations, and career milestones.

## Tech Stack

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Lucide Icons, Shadcn UI
- **Routing & State**: React Router, TanStack Query
- **Styling**: Tailwind CSS & Tailwind Animate

## Getting Started

### Prerequisites
- Node.js (v18+) & npm

### Installation & Run Locally

```bash
# 1. Clone repository
git clone https://github.com/salmankhan2005/AI-career-coach-full-stack.git

# 2. Navigate to project directory
cd AI-career-coach-full-stack

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```
